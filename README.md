# Mindful Muslim Companion

A Streamlit-based Islamic habit-building and reflection companion with a calm green-and-gold dashboard interface.

## Interface

The frontend follows the supplied visual direction:
- Deep green sidebar
- Green active navigation
- Soft mint workspace background
- White rounded cards
- Warm gold accents
- Islamic-inspired hero skyline
- Dashboard metric cards
- Today's Focus cards
- Quick actions
- Responsive layout

The native Streamlit sidebar is retained so desktop starts expanded while mobile users can open and close navigation using Streamlit's built-in sidebar control.

## Run

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Or double-click `run_app.bat` on Windows.

## Pages

Today • Salah • Quran • Habits • Reflection • Progress • Settings • About

## Note

The application is intended for habit-building and reflection support. It does not provide fatwas or authoritative Islamic rulings.
